# Move-then-Operate

Research code for Move-then-Operate, a hard-switch dual-expert vision-language-action policy built on [OpenPI](https://github.com/Physical-Intelligence/openpi).

This repository is a work in progress. The code and documentation are being revised for remote training and evaluation; this is not the final release.

Detailed setup and usage instructions will be published after the implementation is finalized.
